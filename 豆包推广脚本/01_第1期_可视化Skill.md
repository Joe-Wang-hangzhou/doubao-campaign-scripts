### 1.2 为什么主推红黑树

候选知识点按三条标准比较：产物视觉冲击、痛点真实度、对大学生受众好不好懂。

| 候选 | 视觉冲击 | 痛点真实度 | 对受众好懂 | 结论 |
|---|---|---|---|---|
| **红黑树插入旋转** | 红、黑两种颜色本身就好看；旋转是结点位置在动，只有动起来才看得懂；插一个数能先连锁变色、再绕根旋转、最后换根，开头 8 秒就能出画面 | 计算机学生公认的「劝退」知识点，课本只给插入前、插入后两张静态图；数据结构期末常考，408 考纲的「树形查找」也列了红黑树（录前对照当年考纲原文再核一次） | 没学过的人也看得懂「插一个数，整棵树自己转」；学过的人能拿规则对照，评论区有讨论空间 | **主推** |
| Dijkstra / A* 寻路 | 网格里一圈圈扩散，很好看 | 课本的 dist 填表法能应付考试，痛感一般 | 好懂 | 备选 1 |
| TCP 握手挥手加拥塞控制 | 报文飞行加 cwnd 折线，中等 | 408 计网大题常考，状态名容易混 | 要先懂 seq/ack 字段，门槛中等 | 备选 2 |
| 快排 / 堆排 | 柱状图排序网上已经很多，新鲜感弱 | 中 | 好懂 | 不选 |
| LRU 页面置换 | 以表格为主，动起来的增量小 | 中 | 好懂 | 不选 |
| Cache 映射 | 以地址拆分为主，偏静态 | 高 | 门槛高 | 不选 |

#### 提示词 1 · 第一轮生成（电脑端，工作模式，执行位置选本地电脑）

```
我是计算机专业的学生，正在复习数据结构里的红黑树（期末和 408 都考）。课本上插入只有插入前、插入后两张静态图，看不出中间是怎么变色、怎么旋转的。请帮我做一个「红黑树插入过程」的可交互动态图解，做成网页。

一、知识点范围
1. 只讲插入，不讲删除。
2. 红黑树性质按教材通用版本，共 5 条：①每个结点非红即黑；②根结点是黑色；③叶子（空结点 NIL）是黑色；④红结点的两个孩子都是黑色，即不能出现连续两个红结点；⑤从任一结点到其所有叶子的路径上，黑结点数量相同。
3. 新插入的结点一律先染红。插入后的修复分下面几种情况，每一步都要判断属于哪一种：
   - 情况0：插入的是根，直接染黑。
   - 情况1：父结点是黑色，不用调整，直接结束。
   - 情况2：父红、叔红：父和叔染黑，祖父染红，然后把祖父当成新的当前结点继续往上检查。
   - 情况3：父红、叔黑（叔为 NIL 也算黑）：按当前结点、父、祖父的形态分 LL、RR、LR、RL 四种。LL 右旋祖父；RR 左旋祖父；LR 先左旋父再右旋祖父；RL 先右旋父再左旋祖父。旋转后新的子树根染黑，原来的祖父染红。
4. 默认插入序列：10, 20, 30, 15, 12, 5, 1, 3, 25, 28。这个序列会依次碰到上面所有情况，包括「情况2 变色后往上传，到上一层再触发旋转」。

二、动画怎么分步
每插入一个数，拆成下面 5 个小步，每个小步都能单独播放：
1. 找位置：从根往下比较，当前比较的结点高亮，旁边写「28 > 12，往右走」这样的比较说明。
2. 挂结点：新结点以红色出现在对应位置。
3. 判断情况：在结点旁边标出「父」「叔」「祖」，说明栏写出属于哪种情况、为什么。
4. 执行调整：变色时颜色渐变过去；旋转时结点沿弧线平滑移动到新位置，连线跟着重画，不要瞬间跳变；把旋转轴结点标出来。
5. 检查结束：如果要继续往上检查，标出新的当前结点，回到第 3 小步；全部满足性质后显示「插入完成，满足红黑树性质」。

三、交互控件
1. 播放 / 暂停。
2. 上一步、下一步：按小步走，可以倒退到任意一步，树的形状和颜色要完全还原。
3. 速度滑块：0.25x、0.5x、1x、1.5x、2x，默认 1x。
4. 输入框：输入一串用逗号或空格分隔的整数作为插入序列；旁边放「随机生成 10 个数」和「重置」按钮；有重复值或非数字时给出提示。
5. 底部进度条，显示「第 x 个数 / 共 y 个，第 m 小步 / 共 n 小步」。

四、配色和风格
1. 深色背景，用 #0F172A。
2. 红结点 #EF4444；黑结点用 #111827 填充，加浅灰色 #CBD5E1 描边，保证在深色背景上看得清；结点里的数字用白色。
3. 当前操作结点外圈用琥珀色 #F59E0B 高亮；「父」「叔」「祖」标签用青色 #22D3EE。
4. 连线细、干净；NIL 叶子默认不画，给一个开关可以显示。
5. 整体简洁，像正式的课程演示：不要卡通元素，不要表情符号，页面里不要出现任何 logo 和水印。字体用系统无衬线字体，中文清晰。

五、讲解文字
1. 画面右侧固定一个说明栏，每一小步都写一句说明，讲清「现在在做什么、为什么这样做」。例如：「插入 1：父结点 5 是红色，叔结点是 NIL（算黑色），1 是 5 的左孩子，5 是 10 的左孩子，属于 LL 型，对 10 右旋，然后 5 染黑、10 染红。」
2. 说明用中文短句，术语和教材一致：父结点、叔结点、祖父结点、左旋、右旋。
3. 说明栏下方列出红黑树的 5 条性质，当前这一步在检查哪一条，就高亮哪一条。

六、输出形式
1. 做成一个单独的 HTML 文件，HTML、CSS、JavaScript 写在同一个文件里，不依赖任何外部网络资源，双击就能在浏览器打开。如果有可视化相关的技能可以调用。
2. 页面适配 1920×1080 全屏展示，也要能在手机竖屏上正常查看。
3. 做完先自己在浏览器里把默认序列完整跑一遍，检查每一步的旋转和变色是否符合上面的规则；最后用列表告诉我每个数插入时分别触发了哪种情况。
4. 如果支持，生成一个可以分享给同学的链接。
```

```
【第1期提示词，复制到豆包工作模式里用】
```

### 6.4 风险点与预案

- **生成的旋转逻辑出错**：红黑树写错一步，评论区会被懂行的人指出来，伤可信度。必须按 6.5 逐步核对，核对过程本身也是素材

## 8. 备选选题

### 备选 1：Dijkstra 和 A* 寻路同屏对比（数据结构 · 图）

- **身份**：计算机专业在读，复习数据结构图论一章，或者在做算法课设
- **功能**：豆包工作模式（豆包Agent）可视化能力生成网格寻路的交互动画；迭代时加画墙、拖动起点终点、切换启发函数；沉淀 Skill，生成分享链接
- **痛点/场景**：课本里 Dijkstra 是一张 dist 表一行行填，考试会填表，但说不清为什么每次挑最小的那个；A* 课上一句话带过。场景：上课路上用手机远程让宿舍电脑接着改（双端互通）；图书馆闭馆、电脑没电，用手机进云电脑接着做（云电脑）
- **选题详情**：左右两个同样的网格，同一个起点和终点，Dijkstra 一圈圈往外扩，A* 朝终点方向走，实时显示各自访问了多少个格子；鼠标可以画墙、拖起终点，启发函数可选曼哈顿距离或欧几里得距离；下方同步显示 dist 数组，和课本填表法一一对应
- **一句话钩子**：考试填的那张 dist 表，原来是这么一圈圈扩出去的
- **简版大纲**
  - 0-25s：开头放两边同时寻路的画面，A* 先到终点，报出两边访问格子数（以实际跑出的数字为准）；揭晓豆包Agent做的
  - 25-55s：第一步，电脑版工作模式里发提示词，生成基础版
  - 55-85s：第二步，迭代加画墙、拖动、dist 表同步；上课路上用手机远程让宿舍电脑接着改
  - 85-115s：第三步，沉淀 Skill；图书馆闭馆后用手机进云电脑做「图」整章框架图；分享链接
  - 115-135s：权益口径，置顶评论，预告下期

### 备选 2：TCP 三次握手、四次挥手加拥塞控制（计算机网络）

- **身份**：计算机专业在读，计网课期末复习或准备 408
- **功能**：豆包工作模式（豆包Agent）可视化能力生成报文时序加状态机的交互动画，迭代加入丢包重传和 cwnd 曲线；沉淀 Skill，生成分享链接
- **痛点/场景**：课本时序图上 SYN、ACK、seq、ack 一堆数字，SYN_SENT、TIME_WAIT 这些状态背了就混；拥塞控制的 cwnd 折线图会画，但说不清丢包那一刻发生了什么，408 计网大题常考。场景：食堂排队用手机远程让宿舍电脑加丢包功能（双端互通）；宿舍断网后用手机进云电脑接着做（云电脑）
- **选题详情**：左右两台主机，中间报文飞过去，每个报文带 seq 和 ack 数字，两边的状态名随报文变化高亮；可以手动点「丢一个包」看超时重传和快重传；下半屏 cwnd 随传输轮次实时画出折线，慢开始、拥塞避免、快重传、快恢复每个阶段有说明；可调速、可倒退
- **一句话钩子**：点一下丢个包，cwnd 当场减半，这张图终于动起来了
- **简版大纲**
  - 0-25s：开头放丢包后 cwnd 骤降、重传的画面；揭晓豆包Agent做的
  - 25-55s：第一步，发提示词生成三次握手和四次挥手的报文动画
  - 55-85s：第二步，迭代加丢包按钮和 cwnd 曲线；食堂排队用手机远程让宿舍电脑接着改
  - 85-115s：第三步，沉淀 Skill；宿舍断网后用手机进云电脑做「传输层」整章框架图；分享链接
  - 115-135s：权益口径，置顶评论，预告下期
