2. **关键词强制露出**：口播中必须自然出现「**豆包工作模式**」与「**豆包Agent**」。

4. **画面禁忌**：
   - 全程人不出镜，纯电脑录屏（配合 Mac iPhone 镜像展示手机端）。
   - 严禁出现豆包官方 Logo 与二创吉祥物形象。
